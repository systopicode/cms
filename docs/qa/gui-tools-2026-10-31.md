## Implementation notes

- Identical-file comparison groups local originals by byte size, then streams SHA-256 in 1 MB chunks with a five-second hashing budget. External media/generated formats are excluded. Partial/unreadable results never claim a complete all-clear.
- Long press uses the shared recognizer. It calls the same crop toggle function as the button directly, because the shared recognizer deliberately suppresses the terminating click.
- No new notification, spinner, toolbar or state subsystem was introduced.
